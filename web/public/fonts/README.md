# Bundled fonts

Latin subsets (converted to WOFF) of:

- **Lora** (variable, roman and italic): SIL Open Font License 1.1
- **Poppins** (Regular, Medium, Bold): SIL Open Font License 1.1
- **DejaVu Sans Mono** (Regular, Bold): Bitstream Vera and DejaVu free license

They are bundled so the site works offline and makes no third-party requests.

The applicable license and copyright notices are included next to these fonts in
`OFL.txt` and `DEJAVU-LICENSE.txt`. The OFL covers both Lora and Poppins.
